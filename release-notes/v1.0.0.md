## Framily 1.0.0

First public release of Framily - a self-hosted digital photo frame system. Family members upload
photos through a web app to a shared gallery, and a physical e-ink frame device polls the server
and displays them at home. No cloud service, no subscription - your photos and the frame stay on
your own server.

### Highlights

- **Framilies** - a shared photo circle bound to one physical frame, with member roles and invites.
- **Captions** on pictures, shown on the frame alongside the uploader's name and date.
- **E-ink tuned display** - pictures are automatically preprocessed (contrast/brightness) for the
  frame's 6-color Spectra e-paper panel, with an adjustable preprocessing intensity.
- **Configurable frame behavior** - display interval and orientation are set from the web app and
  picked up by the frame on its next fetch.
- **Zero-touch Wi-Fi provisioning** - a brand-new frame boots into its own hotspot with a QR code;
  connect once from a phone to hand it your Wi-Fi and server address.

### Getting started

- **Server**:
  ```sh
  docker pull ghcr.io/gdamms/framily:1.0.0
  ```
  or see the [self-hosting guide](https://github.com/gdamms/framily#self-hosting-production) for
  the full docker-compose stack.

- **Frame**: on a fresh Raspberry Pi, as root:
  ```sh
  curl -sL https://raw.githubusercontent.com/gdamms/framily/main/frame/scripts/install.sh | sh
  ```
  See [frame/README.md](https://github.com/gdamms/framily/blob/main/frame/README.md) for hardware
  requirements and first-boot setup.
